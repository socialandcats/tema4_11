# Тема 4 · Обществознание и котики

Все файлы лежат в одной папке, рядом с index.html. Никаких вложенных папок.

Как выложить: GitHub → репозиторий → Add file → Upload files → перетащить ВСЕ файлы → Commit changes.
Потом Settings → Pages → Deploy from a branch → main → / (root) → Save.

Ссылка на Telegram — строка const TG_LINK= в начале блока <script> в index.html.
Диаграмма к заданию 13 (БАЗА) — объект CHART13: три значения подобраны (2014 «не хотят отчуждения» 15, 2024 «не готовы» 40, 2024 «другое мнение» 10), поменяйте, если есть оригинал.
Шрифт Lazydog: положите Lazydog.ttf или Lazydog.woff2 рядом с index.html — заголовки переключатся сами.
